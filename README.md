# ПОС: 9-этажный 4-секционный жилой дом (ТП 148-037сп/1.2), г. Норильск

Пояснительная записка к курсовому проекту «Проект организации строительства» по 21 разделу задания
(состав раздела 6 ПОС по Постановлению Правительства РФ № 87, МДС 12-81.2007). Продолжительность
строительства рассчитана по МДС 12-43.2008.

| Вариант | |
|---|---|
| Типовой проект | 148-037сп/1.2 — блок-секция 9-этажная 18-квартирная с двойным поворотом прямая 4Б–4Б |
| Количество секций | 4 |
| Район строительства | г. Норильск |
| Начало строительства | 01.12.2027 |
| Дополнительные условия | свайный фундамент |

## Файлы

- `POS_148-037sp-1.2_Norilsk.docx` — пояснительная записка (Word, 66 с., оглавление с номерами страниц);
- `POS_148-037sp-1.2_Norilsk.pdf` — та же записка в PDF;
- `figures/` — рисунки отдельными файлами: календарный план и график движения рабочих, схема стройгенплана,
  схема к подбору крана, транспортная схема;
- `src/` — расчёт и генерация документа (все числа в тексте, таблицах и на рисунках берутся из `src/pos/calc.py`).

## Что принято условно и что стоит проверить перед сдачей

- Титульный лист: вписать вуз, кафедру, дисциплину, ФИО.
- Земельный участок, соседняя застройка и расстояния до местных предприятий приняты условно.
- Климатические данные взяты по Справочному пособию к СНиП 2.01.01-82 и данным метеостанции; сверить с
  действующей редакцией СП 131.13330. Сейсмичность («менее 6 баллов») — сверить по картам ОСР-2015 (СП 14.13330).
- Количество свай — ориентировочный расчёт при допускаемой нагрузке на сваю 600 кН.
- Коэффициент 1,2 к трудоёмкости типового проекта принят по аналогии с северным коэффициентом п. 1 МДС 12-43.2008.
- Добавка на сваи (10 рабочих дней на 100 свай, 22 рабочих дня в месяце) — по Пособию к СНиП 1.04.03-85*.
- Характеристики крана КБ-405.1А — по таблице производителя; при оформлении сверить с паспортом крана.
- Нормы площадей временных зданий и складов — по «Расчётным нормативам для составления ПОС» с увеличением
  для Крайнего Севера; если в методичке кафедры другие значения, поменяйте их в `src/pos/calc.py`.

## Пересборка

```bash
pip install -r requirements.txt
```

```bash
cd src && python3 build.py
```

Для PDF и номеров страниц в оглавлении нужен LibreOffice (`soffice`). Без него — `python3 build.py --no-pdf`:
будет только DOCX, а оглавление Word обновит при открытии.
